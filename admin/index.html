SMS notifications

Automatically texts customers a thank-you message when they submit any form, and sends daily reminders counting down to a confirmed site visit date. Uses Arkesel — sign up for a free account, grab your API key from their dashboard, and paste it below to switch this on.

Max 11 characters, must be pre-approved in your Arkesel account.

Send a test SMS

Send a one-off test text to any phone number to confirm your API key, sender ID, and delivery are actually working — without needing to submit a real form. Doesn't use a message template.
